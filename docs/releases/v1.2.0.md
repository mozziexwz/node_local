## MSBOOST 本地版 v1.2.0

**系统要求**：64 位 Windows 10 或 Windows 11。服务器为 Debian 11–13，root 能用密码或私钥登录，并能访问 GitHub。MSBOOST 启动器请用 v1.2.0 或更新版本：本程序部署的配置同时支持 TCP 和 UDP，更早的启动器会把两种混着用。

### 下载与使用

1. 下载 `MSBOOST-Local-v1.2.0-win-x64.zip`，解压到 MSBOOST 启动器所在的文件夹（和 `MSBOOST-Launcher.exe` 放在一起），部署出的配置会直接出现在启动器里。包里的说明文件名都带 `MSBOOST-Local-`，不会覆盖启动器自己的文件。
2. 双击 `MSBOOST-Local.exe`，不需要管理员权限。
3. 点「添加」，填写服务器的 IP 和 SSH 端口，核对并信任服务器指纹；选中服务器点「部署节点」，输入 root 密码。
4. 完成后点右上角的「打开启动器」，在启动器里选中新配置，开始加速。

从 v1.1.0 或 v1.0.0 升级：先关掉程序，再用新 zip 里的文件覆盖旧文件。`local` 文件夹（服务器列表、任务记录和设置）原样保留。

### 安全提示

- **密码不离开这台电脑**：SSH 密码和私钥口令只在内存里使用，不经过 MSBOOST 网站，也不保存到硬盘。
- **SmartScreen**：本程序没有代码签名，Windows 可能提示「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」。
- **杀毒软件误报**：少数杀毒软件可能误报没有签名的新程序。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - `SHA256SUMS.txt` 列出了两个 zip 的 SHA-256；
  - 解压后的 `MSBOOST-Local-SHA256SUMS.txt` 列出了包里每个文件的 SHA-256。

### 卸载

先在程序里卸载服务器上的节点和中转（想保留可以不卸），再删除 `MSBOOST-Local.exe` 和旁边的 `local` 文件夹。本程序不改系统设置，也不在别处留下文件。

### 更新内容

- **部署和升级节点时配置 fail2ban，保护服务器的 SSH**，和开启 BBR、同步系统时间一样自动完成：
  - 同一 IP 15 分钟内输错 5 次 SSH 密码，封禁 1 天，再犯翻倍，最长 1 周，封禁记录保留 30 天。只封 SSH 端口，节点端口不受影响。
  - 这台电脑所在的网段（IP 的前两段）不会被封，家里宽带换了 IP 一般也还在这个网段里。开了 SSH 代理时，按代理的出口算。
  - 服务器上已经有自己的 fail2ban 配置时，不安装也不改动。本程序只写两个带标记的文件（`/etc/fail2ban/jail.d/zz-msboost.conf`、`/etc/fail2ban/fail2ban.d/zz-msboost.conf`），之后自己写的 `jail.local` 优先。
  - 进度里多了「配置 SSH 防护」一步，结果里多了「SSH 防护」一行。这一步没成功时会撤回它的改动，节点照常部署完成。
  - 已部署的节点点一次「升级节点」就会补上。
  - 卸载节点不会卸载 fail2ban。从别的地方登录时自己的 IP 被封了，在服务商的网页控制台登录 VPS，执行 `fail2ban-client unban <IP>` 解封。
- 执行引擎同步自 MSBOOST 网站 v2.12.0，节点安装脚本没有变。
