## MSBOOST 本地版 v1.1.0

**系统要求**：64 位 Windows 10 或 Windows 11。服务器为 Debian 11–13，root 能用密码或私钥登录，并能访问 GitHub。

**请先把 MSBOOST 启动器升级到 v1.2.0 或更新版本**：本版部署和升级出的配置同时支持 TCP 和 UDP，会直接替换启动器里这台服务器的配置。v1.1.2 及更早的启动器会把 TCP 和 UDP 混着用，网络限制 UDP 时会有一部分连接失败。

### 下载与使用

1. 下载 `MSBOOST-Local-v1.1.0-win-x64.zip`，解压到 MSBOOST 启动器所在的文件夹（和 `MSBOOST-Launcher.exe` 放在一起），部署出的配置会直接出现在启动器里。包里的说明文件名都带 `MSBOOST-Local-`，不会覆盖启动器自己的文件。
2. 双击 `MSBOOST-Local.exe`，不需要管理员权限。
3. 点「添加」，填写服务器的 IP 和 SSH 端口，核对并信任服务器指纹；选中服务器点「部署节点」，输入 root 密码。
4. 完成后点右上角的「打开启动器」，在启动器里选中新配置，开始加速。

从 v1.0.0 升级：先关掉程序，再用新 zip 里的文件覆盖旧文件。`local` 文件夹（服务器列表、任务记录和设置）原样保留。

### 安全提示

- **密码不离开这台电脑**：SSH 密码和私钥口令只在内存里使用，不经过 MSBOOST 网站，也不保存到硬盘。
- **SmartScreen**：本程序没有代码签名，Windows 可能提示「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」。
- **杀毒软件误报**：少数杀毒软件可能误报没有签名的新程序。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - `SHA256SUMS.txt` 列出了两个 zip 的 SHA-256；
  - 解压后的 `MSBOOST-Local-SHA256SUMS.txt` 列出了包里每个文件的 SHA-256。

### 卸载

先在程序里卸载服务器上的节点和中转（想保留可以不卸），再删除 `MSBOOST-Local.exe` 和旁边的 `local` 文件夹。本程序不改系统设置，也不在别处留下文件。

### 更新内容

- **节点支持 UDP**：
  - 部署和升级节点时，节点在同一端口同时提供 TCP 和 UDP，配置文件也同时写两种。用哪种在启动器 v1.2.0 里选；UDP 连不上时启动器会自动改用 TCP。哪种更好要看网络，有的运营商会限制境外 UDP。
  - 服务器上的防火墙（ufw、firewalld）会自动放行。服务商网页控制台里有安全组的话，还要在那里放行同一端口的 UDP。
  - 升级只开了 TCP 的旧节点时会开启 UDP，入口和认证不变，原来的配置照常能用。
  - 部署、升级和取回配置的结果多了 UDP 一行。本程序在 Windows 上查不了 UDP，请在启动器里选 UDP，用「网络检测」确认。
- **自备中转支持 UDP**：节点配置带 UDP、端口不低于 1024 时，中转服务器和前置机也中转 UDP，新配置同时支持 TCP 和 UDP。接近限速上限时 UDP 只能跑到四成左右，游戏本身用不到这么多。
- **朋友中转支持 UDP**：
  - 节点支持 UDP 时，「我用朋友的中转」复制的文字末尾会带「· 支持 UDP」。朋友建中转时 TCP 和 UDP 都中转，发回的入口也带这个标记，生成的新配置就能选 UDP。
  - 建中转前，中转服务器会先检查朋友节点的 UDP 端口：对常见查询有回应、端口没开或者检查不了时，只中转 TCP，结果里写明原因。这样中转服务器不会被人拿去做 UDP 反射攻击。
  - 有一方还在用 v1.0.0 时只走 TCP，照常能用。
- **中转列表**：中转 UDP 的那一行标出「支持 UDP」，「复制入口」复制的文字也带这个标记。
- 执行引擎和节点安装脚本同步自 MSBOOST 网站 v2.11.0。
