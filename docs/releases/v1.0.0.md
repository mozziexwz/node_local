## MSBOOST 本地版 v1.0.0

**系统要求**：64 位 Windows 10 或 Windows 11。服务器为 Debian 11–13，root 能用密码或私钥登录，并能访问 GitHub。

### 下载与使用

1. 下载 `MSBOOST-Local-v1.0.0-win-x64.zip`，解压到 MSBOOST 启动器所在的文件夹（和 `MSBOOST-Launcher.exe` 放在一起），部署出的配置会直接出现在启动器里。包里的说明文件名都带 `MSBOOST-Local-`，不会覆盖启动器自己的文件。
2. 双击 `MSBOOST-Local.exe`，不需要管理员权限。
3. 点「添加」，填写服务器的 IP 和 SSH 端口，核对并信任服务器指纹；选中服务器点「部署节点」，输入 root 密码。
4. 完成后点右上角的「打开启动器」，在启动器里选中新配置，开始加速。

### 安全提示

- **密码不离开这台电脑**：SSH 密码和私钥口令只在内存里使用，不经过 MSBOOST 网站，也不保存到硬盘。
- **SmartScreen**：本程序没有代码签名，Windows 可能提示「Windows 已保护你的电脑」。点「更多信息」，再点「仍要运行」。
- **杀毒软件误报**：少数杀毒软件可能误报没有签名的新程序。可以把程序文件夹加入白名单，或者向杀毒软件厂商提交误报。
- **校验文件**：
  - `SHA256SUMS.txt` 列出了两个 zip 的 SHA-256；
  - 解压后的 `MSBOOST-Local-SHA256SUMS.txt` 列出了包里每个文件的 SHA-256。

### 卸载

先在程序里卸载服务器上的节点和中转（想保留可以不卸），再删除 `MSBOOST-Local.exe` 和旁边的 `local` 文件夹。本程序不改系统设置，也不在别处留下文件。

### 更新内容

首个正式版本。在自己的电脑上用 SSH 部署和管理 MSBOOST 节点与中转，SSH 密码不经过网站。

- **服务器**：添加时读取并固定服务器指纹，指纹变化时拒绝连接；用密码或私钥登录，也可以经本机 SOCKS5 代理连接。
- **节点**：部署、升级（保留配置）、取回配置、查看状态、卸载；部署和升级显示中文进度。
- **中转**：建自备中转（可加前置机）；列出服务器上的全部中转（包括网站建的），可以暂停、恢复、限速、删除或全部卸载。
- **朋友中转**：帮朋友建中转，或用朋友的中转生成新配置。双方只交换 IP 和端口，都不交出 SSH 或节点密码。
- **和启动器配合**：配置直接存进启动器的 configs 文件夹；找不到启动器时提醒；右上角可以直接打开启动器。
- **任务记录**与便携使用：数据都在程序旁边的 local 文件夹里，不含密码。
