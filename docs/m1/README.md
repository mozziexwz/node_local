# M1 实机测试：界面、部署与节点管理

界面按 [样稿第 2 版](mockups.html) 实现。M1 包含「服务器」「任务记录」「设置与关于」三个标签；「中转」和「朋友中转」在 M2 加上。

## 准备

- 一台临时 VPS：Debian 11/12/13，有公网 IPv4，root 能用密码（或私钥）登录。
- `MSBOOST-Local.exe`：从 CI 构件 `MSBOOST-Local-dev-<提交号>-windows-x64` 下载。
- 把 `MSBOOST-Local.exe` 放进启动器所在的文件夹（和 `MSBOOST-Launcher.exe` 放在一起）。这样部署出的配置会直接存进启动器的 `configs`，状态栏右边显示「启动器在同一文件夹」。
- 本程序不需要管理员权限，双击运行即可。

## 步骤

1. **第一次打开**：显示「开始使用」引导；关掉再打开不报错。
2. **添加服务器**：点「添加」，填 IP，点「读取指纹」。
   - 预期：显示指纹（ECDSA 或 ED25519）。点「信任并保存」后，服务器出现在左侧列表。
   - 再添加一次同一个 IP 和端口，应提示「已经在列表里」。
3. **刷新状态**：新系统上显示「未部署 · Debian 12」。
4. **部署节点**：点「部署节点」，输入 root 密码。
   - 预期：右边按顺序勾选十个中文步骤，状态栏显示已用时间。
   - 完成页显示「节点服务 运行中、本机自测 通过、本机到节点端口 可达」，配置保存在启动器的 `configs`。
   - 在启动器的「节点配置」里选中这份配置，「网络检测」应正常；有条件的话进一次游戏。
5. **取回配置**：完成后文件名不变，覆盖原来那份。
6. **升级节点**：步骤跑完，提示「配置没有变化」；启动器里原来的配置照常连接。
7. **重新部署**：会先提醒「旧配置会立即失效」。完成后配置文件还是原来的名字，但内容是新配置；用新配置能连。
8. **部署中取消（可选）**：部署进行到一半时点「取消」，显示「已取消」。等 5 分钟后点「取回配置」，应能拿到配置。
9. **密码输错**：输入错误密码，应提示「SSH 认证失败」，「任务记录」里有一条失败记录。
10. **卸载**：点「卸载…」，输入密码。
    - 预期：先列出要删除的文件，确认后显示「卸载完成」，列表里这台服务器变成「未部署」。
    - 启动器里那份配置已失效，可以删掉。
11. **私钥登录（可选）**：用「编辑」把登录方式改成私钥文件，再刷新状态。私钥有口令时会弹框询问口令。
12. **SSH 代理（可选）**：在「设置与关于」里打开并保存，再刷新状态，应能正常连上。
13. **关闭窗口**：部署进行中关窗口，应弹出确认提示。
14. **隐私检查**：用记事本打开 `local\servers.json`、`local\tasks.json` 和 `local\logs` 里的日志，里面不应出现 SSH 密码。
