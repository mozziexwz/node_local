# M2 实机测试：中转与朋友中转

界面按 [样稿第 2 版](../m1/mockups.html) 实现，M2 加上「中转」和「朋友中转」两个标签。2026-10-22 起界面文案一律说「中转」，不说「转发」，所以样稿里的「朋友转发」改名为「朋友中转」。另外，打开程序时如果找不到启动器，窗口顶部会提醒；窗口右上角有「打开启动器」按钮。

## 准备

- 节点服务器 A：已经部署好节点（M1 测试用的那台就行），启动器里有它的配置。
- 中转服务器 B：另一台 Debian 11/12/13 VPS，有公网 IPv4，能访问 GitHub（要下载中转组件）。B 上有没有节点都可以。
- 前置机 C（可选）：第三台同样条件的 VPS，只在第 5 步用。
- 服务商有安全组或防火墙的话，B 和 C 要放行 TCP 高位端口。中转入口端口是随机的，建好后会显示。
- `MSBOOST-Local.exe`：从 CI 构件 `MSBOOST-Local-dev-<提交号>-windows-x64` 下载，放进启动器所在的文件夹。
- 在「服务器」页添加 B（和 C），读取并信任指纹。

朋友中转的两方可以都由你自己扮演：「我帮朋友中转」用 B，「我用朋友的中转」用 A 的配置。

## 步骤

### 启动器

1. **找不到启动器时提醒**：把 `MSBOOST-Local.exe` 复制到一个没有启动器的空文件夹里打开。
   - 预期：窗口顶部出现黄色提醒「没有在本程序所在的文件夹找到 MSBOOST 启动器…」，状态栏右边显示「还没找到启动器」。
   - 点「知道了」提醒消失，关掉再打开会再提醒。
   - 点「指定启动器位置…」选中 `MSBOOST-Launcher.exe` 后，提醒消失，状态栏显示启动器的位置，以后打开也不再提醒。在「设置与关于」里点「忘记」，提醒又会出现。
   - 测完删掉这个文件夹（程序在里面建了 `local\`）。
2. **打开启动器**：点窗口右上角的「打开启动器」。
   - 预期：Windows 询问管理员权限，同意后启动器打开；启动器已经开着时（包括缩在托盘里），会把它的窗口调出来。拒绝管理员权限不报错。
   - 找不到启动器时不显示这个按钮。

### 自备中转

3. **新建自备中转**：在「中转」页选中转服务器 B、目标节点选 A 的配置、前置机「不使用」、备注填「测试中转」、带宽 5，点「创建中转」，输入 B 的 root 密码。
   - 预期：一分钟左右显示「中转已建好，入口 B的IP:端口」，配置保存为启动器 `configs` 里的 `测试中转.json`，提示末尾有「打开启动器」。
   - 在启动器里选中 `测试中转.json`，「网络检测」正常，「当前到游戏服务器 IPv4」是 A 的 IP；有条件的话进一次游戏。
   - 中转服务器选成 A 时，表单下方提示「中转服务器就是这份配置的节点本身」，「创建中转」不能点。
4. **中转列表与管理**：在下面的管理区选 B，点「读取列表」，输入 B 的密码。
   - 预期：列出刚建的中转，来源是「自备中转 · 测试中转」。网站建的中转也会列出，来源显示「网站」。
   - 10 分钟内点「暂停」：不再问密码，状态变成「已暂停」，启动器经 `测试中转.json` 连不上；点「恢复」后又能连上。
   - 点「限速」改成 3：带宽一栏变成 3 Mbps。
5. **前置机（需要 C）**：再建一条中转，前置机选 C。
   - 预期：密码框同时询问 B 和 C 的密码；完成后入口是 C 的 IP，用新配置能连。
   - 在管理区选 C 读取列表，能看到来源为「前置机」的一条。
   - 不需要 C 也能测：前置机选成 A（目标节点所在的那台）时，提示「前置机就是这份配置的节点本身」，「创建中转」不能点。

### 朋友中转

6. **节点一方发出请求**：「朋友中转」页切到「我用朋友的中转」，选 A 的配置，点「复制」。
   - 预期：复制的是 `MSBOOST 中转请求 A的IP:端口`，只有地址，没有用户名和密码。
7. **中转一方建中转**：切到「我帮朋友中转」，粘贴上一步的文字，中转服务器选 B，备注填「测试朋友」，点「创建中转」，输入 B 的密码。
   - 预期：输入框旁显示「✓ 目标 A的IP:端口」。建好后出现 `MSBOOST 中转入口 B的IP:新端口 → A的IP:端口`，点「复制」。
8. **节点一方生成配置**：切回「我用朋友的中转」，把上一步的文字粘进「朋友发回的」。
   - 预期：显示「✓ 入口」「✓ 中转目标是你这份配置的节点」「✓ 本机到入口可达」。点「生成配置」后，启动器 `configs` 里多出 `<A的配置名>-经朋友中转.json`，原配置不变；提示末尾有「打开启动器」。
   - 用新配置在启动器里「网络检测」正常，「当前到游戏服务器 IPv4」是 A 的 IP。
9. **贴错时拦住（可选，需要两份不同节点的配置）**：选另一份配置，再粘贴同一段文字。
   - 预期：显示「✗ 中转目标是 …，不是你的节点 …」，「生成配置」按钮不能点。
10. **中转一方管理**：在「中转」页刷新 B 的列表。
    - 预期：朋友那条的来源是「朋友中转 · 测试朋友」，多一个「复制入口」按钮，复制出的文字和第 7 步相同。
    - 点「删除」：提示「删除后朋友就连不上了」，确认后列表里没有这一条；第 8 步生成的配置随之失效。

### 卸载与记录

11. **全部卸载**：在「中转」页选 B，点「全部卸载…」（10 分钟内不问密码，超过会再问）。
    - 预期：先列出要删除的目录、服务和防火墙规则，确认后提示已全部卸载，列表为空；「服务器」页 B 的「这台服务器上的中转」显示没有中转。B 上的节点（如果有）不受影响。
    - 第 3 步的 `测试中转.json` 随之失效，可以删掉。前置机 C 上的那条要在 C 上单独卸载。
12. **任务记录**：「任务记录」里有「新建自备中转」「帮朋友建中转」「管理中转」「卸载全部中转」等记录；点开「帮朋友建中转」能看到发给朋友的那段文字。读取列表不记录。
13. **密码改了（可选）**：读取列表后在 B 上改 root 密码，10 分钟内再在「中转」页点「暂停」。
    - 预期：提示「SSH 认证失败」；再点一次会重新询问密码。
14. **隐私检查**：用记事本打开 `local\relays.json`、`local\tasks.json` 和 `local\logs` 里的日志，里面不应出现 SSH 密码。`relays.json` 只记中转的编号、所在服务器、来源、备注、入口和目标。
